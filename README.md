# Su's Magical Journal · Crystal Journal (English)

English-language copy of the crystal book interface, rendered with real-time WebGL glass refraction. It uses the same Supabase project as the original app, so your data is shared.

- Dev: `npm run dev` (port 5175) · Check: `npx tsc -p tsconfig.json` · Build: `npm run build`
- Node: `export PATH="$HOME/.local/node/bin:$HOME/.local/bin:$PATH"`
- `supabase/functions/` has been translated to English but NOT deployed (the deployed functions are shared with the original app).
